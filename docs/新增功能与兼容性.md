# 新功能与兼容性

## 图谱关系

打开“图谱”，在顶部选择新连线类型，再用“手动连线”拖动起点到终点，或在选中笔记侧栏添加目标。点击已有连线可修改类型。方向始终由箭头表示：

| 类型 | A → B 的含义 |
| --- | --- |
| 相关 | A 关联 B |
| 前置知识 | A 是 B 的前置知识，先学 A 再学 B |
| 包含 | A 包含 B |
| 应用 | A 应用于 B |

连线采用直线，开口V形箭头显示在连线中段并指向目标；点击连线可编辑关系。推荐连线和拖动预览采用同一样式。

可选择任意笔记作为中心，查看一层或两层邻居；邻居搜索同时考虑入边和出边，箭头仍保留原方向。超过300篇笔记时首次进入自动显示一层局部图，界面显示已显示/总笔记数，可切回全图。

新建双链自动写成 `[[id:笔记UUID|显示文字]]`。旧 `[[标题]]` 与 `[[标题|显示文字]]` 继续可用；有多个同名目标时显示候选，选择后显式转换为稳定ID，不会自动挑选另一篇笔记。删除目标后会显示不可用，恢复后重新可用。

## 保存和失败重试

笔记编辑状态分别显示本地草稿和后端同步。失败时可重试；切换、刷新不会删除草稿。恢复的草稿需确认后同步。冲突时可查看两侧差异，合并后再同步。浏览器/桌面宿主禁用本地存储时会明确显示本地保存失败。

评分和专注记录均使用稳定操作编号重试。网络失败后重试原操作；专注计时结果会保留，重复提交不会重复累计。

## 多篇笔记复习提纲

在“笔记”侧栏底部点击“多篇笔记生成复习提纲”。可跨分页和学科选择2–30篇，填写可选复习要求后生成；超过模型输入限额时会明确提示缩小范围。当前窗口的编辑会先同步，冲突或失败需先解决。

生成的是草稿，可编辑标题、保存学科及各节标题/正文。每节来源链接由服务器保留。核对来源、未覆盖笔记或源版本变化的提示后，点击“确认并另存笔记”。原笔记不会被覆盖；新笔记随后可用普通编辑器继续修改。

关闭生成结果会保留服务器草稿；“放弃草稿”需要确认。当前窗口尚未采纳的编辑会在关闭时提示。网络导致保存结果未知时，界面冻结原请求，重试会核实是否已保存，避免重复新建。

## 薄弱知识点学习

从首页的薄弱卡片或“复习 › 卡片库 › 薄弱”进入学习面板。遗忘次数是累计历史；面板同时显示最近评分、当前复习状态以及关联任务，完成任务不等于已经掌握。

可跳转来源笔记及资料原文，用自己的话“补充理解”，或编辑卡片。补充理解追加至来源笔记并保留可撤销修订，不覆盖原文；若其他窗口修改了来源，保留输入并要求先读取新版本再核对提交。来源已删除、缺失或卡片为手动创建时，会明确提示，仍可编辑卡片和创建学习任务。

可选择同学科或通用的进行中计划，也可创建新计划；任务日期、截止日和每日预算沿用现有约束。关联任务的完成状态独立于卡片的评分和复习安排。结果未知的补充理解/建任务操作保留原请求编号，刷新后可重试，不重复追加或建任务。

## 迁移与运行方式

应用启动时在SQLite事务中追加迁移，迁移失败会回滚版本号及表结构。已有V1/V2数据库及备份可迁移；未来版本数据库明确拒绝。V3增加评分版本、幂等回执和旧双链身份绑定；V4增加关系类型及修订中的关系快照；V5增加任务来源卡片字段，旧任务为空值；V6增加资料解析尝试编号，旧资料默认为0。旧双链默认为“相关”，旧修订没有类型时同样按“相关”处理。迁移保留已有笔记、资料、卡片、计划、任务及双链；任务来源卡片被彻底删除时仅清空关联字段，不删除任务。

网页、静态前端和pywebview继续调用同一API；前端构建同步至 `backend/app/web/`，运行不需要Node.js。浏览器草稿仍保存在各自宿主的本地存储中。

恢复前完整暂存并校验数据库和资料，建立安全备份后再替换；普通失败回滚数据库和资料。恢复会等待当前请求、流和解析任务退出，无法续跑的备份任务标记为中断。旧窗口写入在数据集变化后被拒绝并刷新，本地草稿继续保留。

下载备份仍移除API Key；恢复优先保留当前模型配置，恢复前安全备份保留现有Key处理约定。目录名及安全备份位置会在恢复结果中显示。
